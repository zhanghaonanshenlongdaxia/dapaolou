# 打炮楼 3A 级场景优化路线图

> 按性价比排序，先零美术成本的设置项，再道具/资产项。

## 第一阶段：光照与后处理（零美术成本，立竿见影）

### 1.1 反射探针（弹珠质感的命门）
- [ ] 在院子中央放置 Reflection Probe（覆盖整个水泥区）
- [ ] 设置：Type=Realtime（或 Baked），Intensity 0.8-1.0
- [ ] 玻璃弹珠材质：Smoothness 0.9+，Metallic 0-0.1，启用 High Quality Reflections

### 1.2 SSAO 环境光遮蔽
- [ ] URP Renderer Asset 启用 SSAO（Screen Space Ambient Occlusion）
- [ ] 参数：Intensity 0.5-0.8，Radius 0.5m
- [ ] 验证：弹珠与水泥接触处有柔和暗边

### 1.3 阴影质量
- [ ] 主光 Shadow Distance 调整为覆盖院子（~25m）
- [ ] Soft Shadows 开启，Shadow Resolution 2048
- [ ] 弹珠/炮楼：Receive Shadows + Cast Shadows 确认开启

### 1.4 环境音效层
- [ ] 蝉鸣循环音（乡村午后核心氛围）
- [ ] 风声 + 远处鸟叫
- [ ] 挂载到场景 Ambient 音源，随时间系统调节音量

## 第二阶段：材质与细节

### 2.1 水泥地材质
- [ ] 换用带磨损/裂缝/水渍的 PBR 水泥贴图（Albedo + Normal + Mask）
- [ ] 分块水泥：每块颜色/磨损随机微差，避免重复感
- [ ] 沟壕：颜色加深 + 湿度渐变

### 2.2 玻璃弹珠着色器
- [ ] URP/Lit：Surface Type=Transparent，Alpha ~0.85
- [ ] Smoothness 0.95，Reflections 开启
- [ ] 可选：内部色差/气泡（贴图或次表面模拟）

### 2.3 围墙与建筑材质
- [ ] 砖墙：砖缝 Normal Map + 顶部苔藓/风化
- [ ] 建筑主体（房子/棚子）：白墙灰瓦，墙根水渍

## 第三阶段：环境道具与植被（可先用占位，等模型替换）

### 3.1 植被
- [ ] 墙角/缝隙杂草（交叉面片 + alpha 贴图）
- [ ] 大树一棵：树冠 + 随风摆动 shader + 投影覆盖半个院子
- [ ] 可选：盆栽、菜畦

### 3.2 乡村杂物（等模型：水缸/柴堆/农具/石磨/板凳）
- [ ] 按手册场景表摆放
- [ ] 每个道具：接触阴影 + 与地面融合（贴花或颜色过渡）

### 3.3 粒子效果
- [ ] 阳光尘埃/飞絮（午后场景核心氛围粒子）
- [ ] 水坑波光（周期性高光闪烁）
- [ ] 弹珠滚动尘土尾迹（可选）

## 第四阶段：生命感与动画

### 4.1 环境动画
- [ ] 树叶随风摆动（shader 或简单 Transform 摇摆）
- [ ] 炊烟粒子（房子烟囱）
- [ ] 晾晒衣物随风摆动

### 4.2 NPC 生物（手册已有设计）
- [ ] 狗臭豆：趴在树下，偶尔抬头
- [ ] 猫骚咪：墙头走动
- [ ] 鸡：院子边缘啄食
- [ ] 妈妈/弟弟：按时间表在场景中活动

### 4.3 弹珠特效
- [ ] 发射拖尾（Trail Renderer）
- [ ] 撞击粒子（水泥尘/玻璃屑）
- [ ] 吃子瞬间的吸附/消散特效

## 第五阶段：音效完善

- [ ] 弹珠滚动循环音（速度联动音量/音调）
- [ ] 撞击音分级：轻碰/重击/玻璃碎
- [ ] 吃子成功音效 + UI 反馈音
